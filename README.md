# IoT & AI-Driven Precision Soil Health Monitor

An intelligent telemetry simulation and decision-engine framework designed to monitor real-time agricultural soil metrics and detect localized water scarcity conditions. 

## 🛠️ Features
- **IoT Telemetry Simulation:** Simulates multi-variant sensor streams capturing soil moisture, ambient temperature, and macronutrient components.
- **Resource Classification Engine:** Evaluates environmental factors against dynamic thresholds to classify irrigation urgency levels.
- **Data Persistence Pipeline:** Automatically packages operational history into structured JSON reports for downstream predictive analytics.
